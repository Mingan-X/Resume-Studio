# 开发计划

当前稳定基线包含API/空Worker、配置与HTTP边界、数据库迁移和基础设施诊断。以下计划按依赖顺序推进，未实现的目标不视为已交付能力。

## 1. 工程基线

已具备固定依赖和锁文件、ESM/装饰器编译、类型检查、Lint、Node测试、真实服务诊断与项目容器隔离。已有验证范围和限制见[测试文档](testing.md)，运行方式见[部署文档](deployment.md)。

## 2. 工作流持久化与观测

接入官方PostgreSQL Checkpointer及Langfuse，先用合成任务验证，暂不依赖真实简历或模型服务。

验收条件：

- 首次setup、重复初始化保护和Checkpoint表权限隔离通过。
- 进程中断后从同thread恢复，已持久化成功产物不重复提交。
- 首Checkpoint不存在时可依据已保存的任务输入恢复，不能丢失已接收请求。
- 不确定旧执行是否停止时，新恢复thread与业务fence能隔离迟到写入。
- OTel/Langfuse版本真实编译并收到关联span，SDK与服务端兼容。
- 观测服务故障不导致业务失败；脱敏用例验证无合成秘密上报。

## 3. 业务实现顺序

| 能力 | 交付内容 | 验收要求 |
|---|---|---|
| 任务与消息可靠性 | Task/Outbox/Receipt/Event、状态查询、取消、恢复调度 | 请求幂等；publish及ACK前后崩溃不丢任务/不重复报告；重试有界；网络分区/旧执行隔离；DLQ定位与受控重放 |
| 简历文件与证据 | Storage、上传、文字块与结构化简历 | PDF/DOCX正常、损坏、加密、扫描、双栏和表格样本；无任意路径读写；引用逐字可核对；空文本不成功；多任务不串数据 |
| JD与rubric | JD入库/结构化、要求确认、不可变版本、六维标准 | 要求来源可追踪；硬门槛和权重确认后才发布；已发布版本不可原地修改；所有权检查 |
| 岗位召回 | 技能关键词、Qdrant索引、Dense Vector与RRF融合、CandidateSet | 至少100条合成JD；索引幂等；旧版本不混入；维数变化新collection；中文技能相关性标注；失败显式降级 |
| 六维画像与语义匹配 | Profile/Matching节点、结构化判断、预算与部分失败 | 六维齐全；unknown不伪装低分；每条精判要求有结果或明确失败；模型不输出总分；拒绝伪造/越界引用；并发受限 |
| 确定性评分与排名 | 纯函数计算、冻结判断、Top10及调权重算 | 固定输入重复100次一致；空/负/NaN/重复ID/同分/unknown边界；重算无模型调用；原候选第11名可进入新榜单；不足10不补造 |
| 报告与前端 | 前端框架、证据展开、真实进度、不可变报告历史 | 刷新/断网/进程重启仍可查；partial显示覆盖率；SSE按seq补读；前端不自行计算最终分 |
| 质量与发布 | 标注评测集、预算/性能数据、部署与运维 | 20+脱敏简历及100–300 JD；人工标注质量评估；权限/删除链路；故障注入；备份恢复；依赖审计；实测时延目标 |

模型评测关注引用有效率、结构化正确率、unknown合理性、逐要求判断质量、Recall@K/推荐相关性和费用，而不只判断“输出非空”。上线阈值须依据标注数据确定，不预先宣称准确率。

## 4. 变更验收

每项实现说明输入、输出、调用链和故障边界；类型检查、Lint与相关测试通过后进行代码审查与维护者验收。未运行项、服务故障和限制明确记录，不能以元数据范围匹配替代真实运行。分支流程见[CONTRIBUTING](../CONTRIBUTING.md)。

## 5. 后续待决策事项

| 决策 | 当前候选 | 确认条件 |
|---|---|---|
| 六维Rubric | 每维L1–L5及unknown | 行为标准、证据门槛和等级映射；20/40/60/80/100仅为示例 |
| LLM服务商与具体模型 | 未选定 | 结构化输出能力、模型标识/版本、数据区域、预算 |
| Embedding模型 | 未选定 | 中文技能检索效果、向量维数、模型版本、费用、区域 |
| Langfuse部署 | 云端或独立自托管 | 脱敏数据出网范围、资源成本、SDK/服务端版本 |
| 前端框架 | Vue3+TypeScript或React | 交互需求与维护成本，开始实现前再核验版本 |
| 文件范围 | 文本层PDF与DOCX | OCR是否首版必须、费用与隐私；复杂版式质量样本 |
| 评分与数据政策 | unknown单列、硬条件待核实、eligible进Top10 | 目标岗位类型、权重、真实数据授权与保留时间 |

已确定技术方向不因上述配置待定而重新选型。不提前添加没有明确需求的组件。
