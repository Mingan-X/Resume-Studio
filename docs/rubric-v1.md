# Rubric v1 审核说明

状态：**AI起草，待维护者统一验收审核**。版本为rubric-v1；来源是[需求§2六维定义](requirements.md#2-六维定义)及S2.2-T6，内容见[rubric-v1.json](../resources/rubrics/rubric-v1.json)。本草案不是已批准的能力标准，也没有人工一致性或模型质量指标。

每维完整包含L1–L5，等级映射20/40/60/80/100。每级都有行为描述、证据门槛及全版本唯一featureId。等级评估的是给定文本能支持的证据强度，不是对人的完整评价；没有覆盖信息时应为unknown，不能自动填L1或0分。应选有证据支持的等级，不因自评、公司名气、岗位头衔、技术名词数量或人口属性升降等级。

证据必须按引用校验器绑定owner和本次输入版本。只允许引用能支持个人职责及具体动作的文本；不能把团队全部成果归为个人，不能从没有写协作经历推断不会沟通，也不能根据年龄、性别等推断成长潜力。指标须保留比较基线和口径，不凭孤立百分比臆造影响。

画像等级不能直接替代某条岗位要求的逐项判断，也不决定硬门槛是否满足。岗位评分公式、unknown覆盖率及排序规则属于S2.5；本文件仅提供版本化画像标准。

维护者统一验收时审核措辞、证据门槛、等级区分和分值映射。审核意见、规则修改或审核状态变化应发布新版本，不原地替换已导入版本；历史任务继续引用原内容哈希。正式模型质量和人工标注评测按路线图延后，不用本草案自评宣称准确率。
